# Zion AI Service Catalog

> One living catalog of every service, owner and dependency.

AI-maintained internal service catalog — ownership, dependencies, SLOs and docs, always up to date. Part of the **Zion AI App Network** — 550+ interlinked AI & IT tools by [Zion Tech Group](https://ziontechgroup.com).

**Live app:** https://ziontechgroup.com/zion-ai-service-catalog/

## Features
- Auto-discovery of services from repos, CI/CD and cloud accounts
- Ownership and on-call mapping synced from your org chart
- Dependency graph with blast-radius visualization
- SLO status per service, surfaced in one view
- Stale-doc and missing-metadata detection
- Backstage-compatible entity export

## Use Cases
- Answer "who owns this service?" in seconds during incidents
- Onboard engineers with a living map of the system
- Track production-readiness across the whole estate
